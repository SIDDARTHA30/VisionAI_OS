# VisionAI-OS

VisionAI-OS is an integrated operating system/platform architecture combining computer vision, intelligent AI reasoning, automated workflow rules, voice capabilities, and responsive dashboards.

## Project Structure

```text
VisionAI-OS/
├── docs/                      # Technical specification, guidelines and tasks list
│   ├── 01_Project_Rules.md
│   ├── 02_System_Architecture.md
│   ├── 03_UI_Guidelines.md
│   ├── 04_API_Documentation.md
│   ├── 05_Database_Design.md
│   ├── 06_Backend_Tasks.md
│   ├── 07_Frontend_Tasks.md
│   ├── 08_AI_Modules.md
│   ├── 09_Testing.md
│   └── 10_Deployment.md
├── frontend/                  # Web dashboard UI
├── backend/                   # Core server API & orchestrator
├── vision/                    # Object detection & camera streaming pipeline
├── automation/                # Trigger & actions rule engine
├── voice/                     # Speech-to-Text and Text-to-Speech logic
├── ai/                        # Local LLM models & command parsing routing
├── database/                  # Schema, migrations & seeds
├── models/                    # Shared entities & DTO validation definitions
├── tests/                     # Unit, integration & end-to-end suites
└── scripts/                   # Development setup & auxiliary utilities
```
