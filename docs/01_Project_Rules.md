# 01. Project Rules

This document outlines the core guidelines, rules, and coding standards for the VisionAI-OS project.

## 1. General Principles
- **Clarity over Complexity**: Write code that is easy to read and understand.
- **Maintainability**: Ensure code is modular, well-documented, and easy to modify.
- **Robustness**: Implement proper error handling and edge-case validation.

## 2. Coding Standards
- **Naming Conventions**: Use consistent, descriptive names for variables, functions, and classes.
- **Formatting**: Adhere to language-specific formatting standards (e.g., PEP 8 for Python, Prettier for Javascript/Typescript).
- **Comments**: Write clear comments for complex logic, but aim for self-documenting code.

## 3. Git Workflow
- **Branching**: Use descriptive branch names (e.g., `feature/voice-control`, `bugfix/vision-latency`).
- **Commits**: Write clear, concise commit messages following conventional commit guidelines.
- **PRs**: Ensure all tests pass and obtain reviews before merging.
